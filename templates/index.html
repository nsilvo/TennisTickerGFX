🔗 API Links (click a link to open, or use Copy)

  • GET {{ base_url }}/api/v1/scores All cached matches — tournament_id, last_updated, refresh_interval_seconds, match_count, matches[].
  • GET {{ base_url }}/api/v1/scores/court/1 Same as above, filtered to one court (replace "1").
  • GET {{ base_url }}/api/v1/match/12345 Single match lookup by matchid (replace "12345"); 404 if not found.
  • GET/POST {{ base_url }}/api/v1/tourid/{{ tournament_id }} Switch the feed tournament being scraped (admin login required).
  • GET {{ base_url }}/api/v1/vmix vMix data source: one flat row per court (use ?court=1 to filter).
  • GET {{ base_url }}/api/v1/vmix/wide?courts=4 Multi-court board feed: one row with columns per court slot.
  • GET {{ base_url }}/caspar/bug/?court=1 Caspar/vMix lower-third bug overlay for a given court.
  • GET {{ base_url }}/caspar/scoreboard/?court=1 Full scoreboard overlay for a given court.
