Import / export bios

Upload a bios CSV (from ⬇ Export CSV, or produced by scripts/lta_scrape.py). Rows with LTA names are matched to players in the feed automatically. Only empty fields are filled unless you tick overwrite.

Match every player in the feed to Padel API (FIP / Premier Padel pros: ranking, Elo, titles, record, partner, age, height, side). Requests are paced to your plan's rate limit, so a full run can take a few minutes; players fetched in the last day are skipped.
Fill the gaps from the FIP website (padelfip.com): players Padel API doesn't cover (e.g. FIP Beyond), season and career win-loss, titles, latest results and coaches. No token needed.
