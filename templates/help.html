📡 Data Flow Overview

Tennis Score Data Flow
🎾 TennisTicker XML Feed
⬇
🐍 Python Scraper (server.py)
- Fetch XML
- Parse names, sets, tie-breaks
- Detect changes
- Cache in SQLite
⬇
🗄 SQLite Match Cache
(casparcg_match_cache.db)
⬇
🔌 Flask-SocketIO
Sends live_updates events → Browser
⬇
🖥 Dashboard Frontend
(index.html)
Updates cards in real time

🔴 LIVE Match Data Structure

LIVE Match Breakdown
Player 1
player1_surname
player1_country
Player 2
player2_surname
player2_country
⬇
Current Game
game1
Current Game
game2
⬇
Set Scores:
set1_p1, set1_p2 … setN_p1, setN_p2
Tie-break: setN_tb
⬇
Server Indicator → player2serve
0 = Player 1 serving
1 = Player 2 serving
FieldDescription
matchidUnique ID
matchstatusShould contain “IN PROGRESS”
game1, game2Current point score
player2serveServing indicator
setN_p1Player 1 set score
setN_p2Player 2 set score
setN_tbTie-break score

Example LIVE JSON:

{
  "matchid": "123",
  "player1": "Ben GUSIC",
  "player2": "Tom WILLIAMS",
  "game1": "40",
  "game2": "AD",
  "player2serve": 1,
  "set1_p1": 6,
  "set1_p2": 4,
  "set2_p1": 3,
  "set2_p2": 5,
  "sets_played_count": 2
}
